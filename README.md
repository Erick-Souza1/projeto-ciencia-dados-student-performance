Projeto de Ciência de Dados utilizando o dataset Student Performance. Análise exploratória, pré-processamento, K-Means e Regressão Linear.

## Dataset

Student Performance

## Objetivo

Analisar os fatores relacionados ao desempenho dos estudantes,
identificando padrões e grupos de alunos com características semelhantes.

Além disso, será desenvolvido um modelo de Regressão Linear
com o objetivo de prever o desempenho dos estudantes.

## Perguntas do projeto

- Quais fatores estão relacionados ao desempenho dos estudantes?
- É possível identificar grupos de estudantes com características semelhantes?
- É possível prever o desempenho de um estudante utilizando as variáveis disponíveis?

## Técnicas utilizadas

- Análise Exploratória de Dados (EDA)
- Pré-processamento dos dados
- K-Means
- Regressão Linear
- Métricas de avaliação

## Etapas do projeto

1. Definição do problema
2. Exploração dos dados
3. Limpeza e pré-processamento
4. Clusterização com K-Means
5. Regressão Linear
6. Avaliação dos modelos
7. Interpretação dos resultados
8. Apresentação dos resultados
